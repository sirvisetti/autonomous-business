# ABCS provenance register

ABCS follows a GREEN-only provenance policy. External material is used only when its terms are sufficiently open for the intended use, and ABCS does not copy external standards wholesale. Canonical definitions are deliberately concise and independently expressed.

## GREEN semantic references

| Source | License / openness | ABCS use |
| --- | --- | --- |
| OASIS Universal Business Language (UBL) 2.4 | Open OASIS specification; implementation-oriented derivative/explanatory use permitted under the OASIS notices | Semantic reference for Procurement, Finance, and Logistics business-document concepts. ABCS does not reproduce the UBL XML model. |
| Financial Industry Business Ontology (FIBO) | MIT | Cross-check for finance vocabulary, parties, obligations, and financial semantic modeling. |
| Eclipse Tractus-X semantic models | CC BY 4.0 | Semantic reference for manufacturing, part, production, material, and supply-chain concepts. ABCS retains attribution and does not reproduce the models wholesale. |
| JSON Schema 2020-12 | Open specification | Normative validation language for ABCS canonical schemas. |

## Reviewed but not used as canonical source material

Open311 GeoReport is a useful public example of service-request semantics. During the Draft 0.2 review, the canonical specification repository did not expose a sufficiently clear license for ABCS to treat it as GREEN source material. ABCS Service models therefore remain Sirvisetti original canonical work unless and until licensing is verified.

Proprietary, paywalled, or licensing-ambiguous frameworks and standards are not used as source material for canonical ABCS definitions.
