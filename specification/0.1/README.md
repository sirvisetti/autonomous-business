# ABCS Draft 0.1

The Autonomy Business Capability Specification (ABCS) is an open, vendor-neutral specification for describing business capabilities so humans, agents, applications, and automation platforms can discover and execute business operations consistently.

Draft 0.1 establishes the core model, canonical identifier convention, machine-readable capability schema, governance principles, and an initial Procurement proof set.

Status: **Draft / pre-1.0**.
